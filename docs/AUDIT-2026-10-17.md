# Canairy audit: is it useful day to day? (Oct 17, 2026)

## Verdict

The data is good; the delivery wasn't. Canairy collects 36 real readings every hour, grades them honestly (stale and experimental readings never raise an alert) and has written "what to do" advice for every core reading. But nothing reached you unless you opened the site, and the Milo hookup never actually texted. So it worked as a reference page, not a daily tool.

This change and the matching brownbot change fix the delivery: Milo now texts when a core reading crosses its act line, puts a short Preparedness section in the morning standup, and adds a task with the specific step.

## What works

| Strength | Why it matters |
| --- | --- |
| 36 live readings from official or market sources, collected hourly | Real numbers, no mock data in the live path (`server/api/collect.py` rejects fallback labels) |
| Honest grading: stale readings show "unknown", experimental ones never alert | An alert means something |
| Every reading has history (10-year percentile) | "Higher than 97% of readings since 2015" beats a bare number |
| Written advice for all 30 core readings, amber and red | The "what to do" exists and is proportionate |
| County readings (FEMA, wastewater, drought, state jobs, gas, power, grocery) and Federal Register benefit rules | Local and policy context most dashboards lack |
| Grounded daily briefing (numbers must come from the data) | No invented statistics |

## What blocked daily use, and what changed

| Problem | Effect | Fix |
| --- | --- | --- |
| No alerts of any kind (no text, email or push) | You had to remember to look | Milo watches the feed (brownbot `src/canairy-watch.ts`) |
| Milo's old check sent its alert as a "decision" | Milo files decisions into the next brief, so it never texted | Red crossings now go out as time-critical texts |
| Milo's old check needed 2+ reds at once | Brent has been red alone for months, so it never fired | One core red is enough to text; reds in two areas at once get a separate "tighten up" text (the research's "shocks together" rule) |
| The advice lived only in the website code | Milo and other feed readers couldn't say what to do | Advice moved to `server/api/advice.json`; the feed now carries `guidance` for each amber or red reading |
| `lastUpdate` is fetch time, not the data's date | Last quarter's GDP looked like today's news | Feed now carries `status.asOf` (the period the number describes) |
| Bond-swing reading (the only "critical" one) read 0 in 284 of 562 readings | Pre-market and weekends read as perfectly calm | Uses the latest trading session's daily bar |
| An old briefing kept leading the page if newer ones failed | Advice could describe last week's numbers | Briefings older than 48 hours are no longer served |
| Measles was red (733 cases in 4 weeks) with no advice | Families with kids got nothing to do | Written advice added (experimental readings can carry advice; they still never alert) |

## Still open (not done here)

- **Dead weight.** Removed on 2026-10-18: the June trip-wire system, old dashboards, Render/Docker/Prometheus files, stale docs and 195 MB of committed build packages (about 5,100 files).
- **Phases.** `/phase` and `/hopi` compute phases 1-6 but the site never shows them, and the Plan checklist still carries bunker-era items (Faraday pouch, safe room). Either tie the checklist to the current readings or drop phases.
- **Fragile sources.** Freightos and TSA are page scrapes; Real Wages failed 108 times since Oct 10 when its two FRED series published on different dates.
- **Misleading ids.** `grid_01_pjm_outages` is really NWS extreme alerts; `bio_01_h2h_countries` is WHO outbreak notices.
- **Trend is always 7 days**, so monthly and quarterly readings nearly always say "stable".
- **SNAP's direction** treats higher as worse, but its own description says a drop is the concern.
- **Vercel cron has no `maxDuration`.** One run covers all collectors, backfill, local pulls, rules and a model call.
- **Research signals not yet added:** days to the next federal funding deadline (Congress.gov), county protest data (ACLED, needs a key), NY Fed student and auto delinquency (quarterly), Treasury auction tails, prediction-market recession odds, EPA AirNow by ZIP and state WARN layoff notices.
- **The outlook isn't on the site yet.** It is API-only; Milo reads it.
